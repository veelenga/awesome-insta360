# Contribution guidelines

Thanks for helping improve this list.

## Adding an entry

- Make sure the project is open source and related to Insta360 cameras.
- Add it to the matching section, keeping the existing order.
- Use the format: `- [name](link) - Short description ending with a period.`
- Keep the description to one sentence. Say what it does, not why it is great.
- Do not add the same project twice.
- One entry per pull request, so it can be reviewed and verified quickly.

## Removing or updating an entry

Open a pull request explaining what changed, for example the project was archived, moved, or no longer works with Insta360 cameras.
